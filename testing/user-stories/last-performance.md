# Last Performance on the Set Card

## Active workout

- When the current exercise has a completed set in an earlier session, the set
  card shows the most useful weight-and-rep result from the latest matching
  session as "Last time".
- Exercise history matches by stable exercise-definition ID so renaming an
  exercise does not hide its previous result. Legacy sets without an ID still
  match by exercise name.
- Weighted exercises show pounds and reps. Body-weight or other zero-weight
  exercises show reps without a zero-pound label. Timed exercises show a
  formatted duration.
- A new exercise with no completed history does not show a "Last time" row.
- Pausing, refreshing, and resuming an active workout retains the previous
  performance reference.
